# 📊 Data Governance Health Check (Excel Tool)

A simple, practical, and lightweight Excel-based tool to assess the current state of data governance.

## 🎯 Purpose

Data governance is often seen as complex and overly corporate.
This tool simplifies it into a structured self-assessment to help answer:

> *“Where does our data actually stand today?”*

## 🧩 What’s Inside

* ✅ 50 assessment questions
* ✅ 5 key domains:

  * Policy
  * Roles & Responsibility
  * Data Quality
  * Security
  * Data Lifecycle
* ✅ Scoring system (1–5 maturity level)
* ✅ Automatic category scoring
* ✅ Radar chart visualization
* ✅ Narrative insights (auto-generated)

## ⚙️ How It Works

1. Fill in the score (1–5) for each question
2. Review the summary dashboard
3. Identify weak areas and prioritize improvements

## 📈 Scoring Scale

| Score | Meaning                  |
| ----- | ------------------------ |
| 1     | Not implemented          |
| 2     | Partially implemented    |
| 3     | Defined but inconsistent |
| 4     | Well implemented         |
| 5     | Optimized and controlled |

## 💡 Use Cases

* Small to mid-sized businesses starting data governance
* Internal data health checks
* Quick assessment before deeper implementation
* Learning and awareness tool
